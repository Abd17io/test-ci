# Interior References — ٦ مواقع تصميم داخلي

مكتبة مرجعية من **٦ مواقع كاملة** لاستوديوهات تصميم داخلي. كل موقع على راوت خاص فيه، بهوية بصرية وأسلوب حركة مختلف، ومستوحى من أقوى مواقع التصميم الداخلي.

| الراوت | الموقع | الأسلوب | مستوحى من | أبرز الحركات |
|---|---|---|---|---|
| `/noir` | Maison Noir | فخامة داكنة، Editorial | Joseph Dirand · Pierre Yovanovitch | Preloader بعدّاد، انتقال ستائر، معرض أفقي مثبّت، مؤشر مخصص، معاينة صور عند المرور |
| `/nord` | Nordhaus | اسكندنافي هادئ | Norm Architects · Menu | صورة تتوسع مع السكرول، قسم مثبّت تتبدل صوره، فلترة بحركة Flip، شريط خامات |
| `/terra` | Atelier Terra | متوسطي دافئ | Studio KO · Cathie Hong | أقواس تنكشف، ختم دوّار، تغيّر لون الخلفية، كروت مكدّسة، خط SVG يُرسم، سلايدر بالسحب |
| `/vanta` | VANTA | جريء وملوّن | Kelly Wearstler · Dimorestudio | أثر صور يتبع الماوس، نصوص تنحرف مع سرعة السكرول، انتقال مائل ملوّن، كروت 3D |
| `/dar` | دار | عربي فاخر RTL | Elite Design Studio | صور تطفو حول الاسم، مقارنة قبل/بعد بالسحب، معرض أفقي RTL، عدّادات |
| `/lumen` | Lumen | فنادق ومطاعم ومكاتب | Yabu Pushelberg · Rockwell Group | زووم سينمائي، تبويبات تلقائية، قسم مثبّت يتبدل نصه، تبديل Grid/List بحركة Flip |

كل موقع فيه: الرئيسية، المشاريع، صفحة تفاصيل لكل مشروع (٥–٦ مشاريع)، من نحن، الخدمات، تواصل (نموذج متحرك). المجموع ٦٣ صفحة.

## التشغيل

الموقع **HTML ثابت** — بدون build على السيرفر، يرفع مباشرة على Hostinger أو أي استضافة.

```bash
# معاينة محلية
python3 -m http.server 8080   # ثم افتح http://localhost:8080
```

## التعديل

الصفحات مولّدة من قوالب في `tools/`:

- `tools/sites/<site>.mjs` — المحتوى والقوالب لكل موقع
- `assets/sites/<site>.css|js` — التصميم والحركات الخاصة بكل موقع
- `assets/core.js|css` — محرك الحركة المشترك (data-split, data-reveal, data-marquee, …)
- `tools/images.mjs` — صور Unsplash المستخدمة

بعد أي تعديل على القوالب:

```bash
node tools/build.mjs
```

## ملاحظات

- الحركة تعمل على كل الأجهزة، **حتى لو خيار "تقليل الحركة" مفعّل** في نظام التشغيل (حسب الطلب).
- المكتبات (GSAP 3.15 مع ScrollTrigger/SplitText/Flip، و Lenis 1.3) محفوظة محلياً في `assets/vendor` — لا تعتمد على CDN.
- الصور من Unsplash (رخصة مجانية). إذا فشل تحميل صورة، تُستبدل تلقائياً بصورة بديلة.
- النماذج (Forms) للعرض فقط: تُظهر رسالة نجاح متحركة ولا ترسل بيانات لأي خادم.
- الأسماء والعناوين والأشخاص في المحتوى وهمية لأغراض مرجعية.
